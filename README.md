
# Expense Tracker 💰

A simple expense management application built using React.js to track earnings, manage expenses, and monitor remaining balance.

## Live Demo
[Expense Tracker](https://expensetracker-rho-green.vercel.app/)

## Features
- Add and manage earnings.
- Add, edit, and delete expenses.
- View total earnings, expenses, and remaining balance.
- Search expenses by title.
- Filter expenses by category and date.
- View category-wise spending summary.
- Save data using localStorage.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- LocalStorage

## Run Locally

```bash
git clone https://github.com/durgabhavani432/Expensetracker.git
cd Expensetracker
npm install
npm run dev
```
