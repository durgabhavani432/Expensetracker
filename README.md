# 💰 Expense Tracker

A simple and user-friendly Expense Tracker application built using **React.js** that helps users manage their earnings, track daily expenses, and monitor their remaining balance.

## 🌐 Live Demo

[**View Expense Tracker Live**](https://expensetracker-rho-green.vercel.app/)

## 📌 Project Overview

The Expense Tracker allows users to enter their earnings, add and manage expenses, and view a summary of their spending. It automatically calculates total expenses and deducts them from the available earnings to display the remaining balance.

## ✨ Features

- **Add Earnings:** Enter and update your total earnings.
- **Add Expenses:** Record expenses with title, amount, category, and date.
- **Edit Expenses:** Modify previously added expenses.
- **Delete Expenses:** Remove unwanted expense records.
- **Total Earnings:** Display the total available earnings.
- **Total Expenses:** Automatically calculate all expenses.
- **Remaining Balance:** Calculate the remaining money after deducting expenses.
- **Search Expenses:** Search expenses by title.
- **Filter by Category:** Filter expenses by Food, Travel, Shopping, and Others.
- **Filter by Date:** Filter expenses by Today, This Month, and This Year.
- **Category Summary:** Display category-wise spending totals.
- **Local Storage:** Save earnings and expense records in the browser using localStorage.
- **Balance Validation:** Prevent adding expenses that exceed the available balance.
- **Responsive Design:** Support different screen sizes.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/durgabhavani432/Expensetracker.git
```

**2. Navigate to the project folder**

```bash
cd Expensetracker
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in browser**

Visit:

```text
http://localhost:5173/
```

## 🏗️ Build for Production

To create a production build, run:

```bash
npm run build
```
